# GenAI Projects

A collection of generative AI and ML engineering projects demonstrating end-to-end system design, evaluation pipelines, and autonomous optimization.

## Projects

| Project | Description | Stack |
|---------|-------------|-------|
| [self-improving-rag](./self-improving-rag/) | A RAG pipeline with autonomous quality control: evaluates its own output, diagnoses failures, and iteratively improves retrieval configuration without human intervention. | Python, LangGraph, ChromaDB, Gemini, Streamlit |

## About

These projects focus on production-oriented AI engineering: evaluation frameworks, feedback loops, observability, and systematic quality improvement rather than just "get an LLM to answer questions."
